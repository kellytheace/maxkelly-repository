Problem 2: Even Fibonacci Numbers

Problem Statement

Each new term in the Fibonacci sequence is generated by adding the previous two terms. By starting with 1 and 2, the first 10 terms will be:

1,2,43,5,8,13,21,34,55,89,...

By considering the terms in the Fibonacci sequence whose values do not exceed four million, find the sum of the even-valued terms.

Theory & Approach

Fibonacci definition

The Fibonacci sequence is generated by adding the previous two terms. With $$F_1=1,\quad F_2=2,$$ every next term is

$$F_n = F_{n-1}+F_{n-2}\,.$$

We only care about terms with $F_n \le 4{,}000{,}000$.

Summing the even terms

The simplest approach is to generate terms in order and keep a running total. Each time we produce a new Fibonacci number, we check if it’s even and add it to the sum if it is.

$$\text{If }F_n \equiv 0 \pmod{2}\text{ then add }F_n\text{ to the total.}$$

Why a loop is fine here

Even though this is a loop, it’s not looping up to four million — it’s looping over Fibonacci terms, which grow quickly. That means there aren’t many terms to generate before we pass the limit, so this runs fast and stays simple.

Python Solution


limit = 4000000

a, b = 1, 2
total = 0

while a <= limit:
    if a % 2 == 0:
        total += a
    a, b = b, a + b

print("result is", total)

Final Answer

4613732
