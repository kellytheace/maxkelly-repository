Problem 3: Largest Prime Factor

Problem Statement

The prime factors of 13195 are 5, 7, 13 and 29. What is the largest prime factor of the number 6000851475143?

Theory & Approach

If $n$ is composite (non-prime), then it has a factor $d$ where

$$d \le \sqrt{n}\,.$$

This is because if both factors were greater than $\sqrt{n}$, their product would be greater than $n$. So to find a factor, you only need to test divisors up to $\sqrt{n}$.

Checking all numbers up to $n$ is slow. Limiting checks to $\sqrt{n}$ and shrinking $n$ as you go cuts down the work, so it runs faster for large numbers.

Python Solution


num=600851475143
arr=[]
while num>1:
    for i in range (2,num+1):
        if num%i==0:
            num=num//i
            arr.append(i)
            break
print(max(arr))

Final Answer

6857
