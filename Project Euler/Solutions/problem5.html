Problem 5: Smallest Multiple

Problem Statement

$2520$ is the smallest number that can be divided by each of the numbers from $1$ to $10$ without any remainder.

What is the smallest positive number that is evenly divisible by all of the numbers from $1$ to $20$?

Theory & Approach

We need the smallest positive number $N$ that is divisible by every integer from $1$ to $20$. By definition, this number is the least common multiple: $$N=\mathrm{lcm}(1,2,\dots,20).$$

Instead of guessing $N$, we build it up step-by-step. If result is divisible by all numbers we have seen so far, then updating

$$\text{result} \leftarrow \mathrm{lcm}(\text{result}, i)$$

makes it divisible by $i$ as well, while keeping it as small as possible. Repeating this for $i=11,12,\dots,20$ gives the final answer.

(Using $11$ to $20$ works because any number divisible by $11$–$20$ is automatically divisible by $1$–$10$.)

Python Solution


import math

result = 1
for i in range(11, 21):
    result = math.lcm(result, i)

print(result)

Final Answer

232792560
